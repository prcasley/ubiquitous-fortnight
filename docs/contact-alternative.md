# Contact alternative A — on demand

Open contact-preview.html through a local HTTP server after npm ci and npm run build. Download the contact-alternative-preview artifact from this PR's Actions run, extract it, run `python3 -m http.server 8090` in that folder, and open http://localhost:8090/contact-preview.html. The full workspace is index.html. This does not deploy to production.

A checks active federal carrier records when requested. The query is paginated, has a timeout, and reports source caps and failures separately from no matches. The lookup supports NJ parcel records in any nominated tract; this is not a claim of complete contact coverage. Exact municipal-name matching can miss postal aliases; these require documented mappings before broadening matching.

Both alternatives reject missing field evidence, old/future observations, and cross-town, directional, street-type and parcel-ID mismatches. Contacts remain businesses at an address, not confirmed owners. Compound-company legacy vault records no longer drive Call buttons. Prepared office contacts have individual source observations. The raw vault remains unchanged for compatibility, but its previous credential has been publicly exposed. The new welcome handler uses only typed input and does not remember credentials; refresh requires entry again. Rotate and re-encrypt with a new private credential before claiming confidentiality. Contact verification does not prove deliverability or authority to sell.

Validation: focused evidence regression tests and static build. Full legacy browser suites need adaptation for the intentional re-entry-on-refresh behavior; this PR stays draft until browser QA and credential rotation are complete. No microphone, physical iPhone, or all-130-tract completion claim.
