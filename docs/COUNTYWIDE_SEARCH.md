# Countywide parcel retrieval

November 4 update: see [Executive research safeguards](EXECUTIVE_OZ_HARDENING.md). Lehigh is now marked unavailable for direct browser access; Broward now uses verified server-side size prefilters before paging.

Explicit county requests use the full connected county source instead of geocoding a county centroid and applying a five-mile circle. NJ uses its published COUNTY field; Palm Beach, Broward, Miami-Dade and Northampton use their county layers. Lehigh remains cataloged for future proxy-based access but is disabled in the browser. Connected Martin and St. Lucie FDOR searches use their county code. City and street-address searches retain their radius behavior.

County scans do not draw a radius circle. Chat, parcel cards and the result list identify countywide coverage. Default acreage ordering covers retrieved records, not an unretrieved countywide ranking. Source records are counted before paging. County FL layer scans retain the 900-feature cap; NJ, PA and connected FDOR retrieval retain the 1,600-feature cap. A cap displays “Partial: first N of M source parcels countywide,” the accepted count, and town/acreage narrowing options. A failed source is not treated as a zero-property finding. Unsupported counties are refused with town options where available; no centroid search is substituted. A radius requested around an entire county boundary is explicitly listed as unapplied; choose a town or address for a radius search.

Broward's existing projection has no published acreage field. Radar validates the parcel metadata and use-code type, follows the published object-ID field for paging, and calculates geodesic acres from the returned WGS84 polygon (including holes/multipart shapes). Full geometry is requested for that calculation. Size comparisons use this computed area. Cards, details, Deal Nav and field packs identify it as computed GIS polygon acreage, not a published lot-size field, surveyed area, owned share or net developable area. Unmeasurable geometries fail explicitly; no size or industrial suitability is inferred.

Read-only API checks on November 3, 2026 confirmed that NJGIN accepts a geometry-free Monmouth filter (`COUNTY`, industrial class 4B, over 10 acres), returning 78 source records. Palm Beach's full industrial-over-10-acre predicate returned 465 source records. Ordered identity-only paging reconciled all 78 NJ and all 465 Palm Beach records without repeated IDs. That check does not establish browser CORS availability or validate every returned polygon. These are live source observations, separate from fixture browser tests and deployed-site verification.

Lehigh and Broward requests from this execution environment were blocked by the outbound proxy with “Tunnel connection failed: 403 Forbidden.” That response does not establish whether the public county service is unavailable or whether the user's earlier failure was local. No replacement Lehigh source was invented. Its countywide request, source schema validation, paging and explicit failure/town-narrowing behavior are covered with synthetic browser fixtures; live Lehigh availability still requires external verification.
