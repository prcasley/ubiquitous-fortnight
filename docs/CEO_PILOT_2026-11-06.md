- All 25 listed PCNs were returned by the official county layer (26 source rows, one repeated parcel ID reconciled).
- All 25 situs/use claims match the source labels after street-suffix normalization. Twenty-four acreage claims match within 0.02-acre rounding; one has conflicting source acreage and is withheld pending review.

- No claimed officer, manager, registered agent, parent-company link, telephone number or sale authority was independently verified. The report's Sunbiz document numbers are preserved only as local claims awaiting a filing check. A registered agent is not necessarily an acquisition decision-maker.

Included are 49 OPEN STORAGE, 14 VACANT INDUSTRIAL and 67 VACANT COMMERCIAL LAND records. Institutional/government records are retained rather than called “never sellers.”

## Five-minute external pilot acceptance

1. Hard refresh `https://prcasley.github.io/ubiquitous-fortnight/` and confirm the intended commit has deployed. Enter the courtesy welcome code if prompted. This screen is a deterrent, not authentication; use public research only.
2. Type “industrial over 5 acres within 2 miles of Edison NJ.” Confirm the announced criteria, source, matching acreage/radius and honest completeness status. Open one parcel; the map and dossier should agree on its ID.
3. Run a West Palm Beach/Mangonia industrial scan. Open a parcel and check its dated assessment and mailing observation. An unavailable field/source must remain explicit; no corporate officer should be labeled verified merely because a report supplied a name.
4. Add two stops, reorder, write a note and generate the field pack. Confirm the map views, order and notes before sharing it.
5. Open the same link on the CEO's phone and type a search. Check map/drawer controls, text sizing and no sideways page scrolling. Voice can be tested separately with microphone consent.

## Shareability and remaining gaps

The WP123 welcome gate does not protect the public HTML or assets. Optional private notes, imported officer claims and generated local review files have not been published. Do not put internal acquisition strategy or confidential files in public assets. Hosted prompts continue to exclude ownership/contact observations and local files.

The main gaps are verified NJ legal-owner coverage, independently verified corporate-role/contact evidence, listing/availability/lease/loan data, automatic zoning/utility capacity, an authenticated persistent backend for optional summaries, and physical-device voice validation. Lehigh's direct-browser source is disabled because it blocks cross-site access; Northampton/Easton has a separate adapter with explicit coverage limits. Nationwide paid-provider parity is not claimed.
