# Research assistant architecture

This earlier roadmap is superseded by [hosted assistant setup](HOSTED_ASSISTANT.md).

The app now uses server-side hosted inference. Browser/local model downloads and self-hosted/Ollama directions from earlier branches do not apply. Executives see only Radar product language.

GIS remains the source of parcel facts. The assistant interprets a bounded public-record sample; it does not discover missing owners, leases, histories or feasibility facts. Private recovery archives and licensed data are not automatically sent to it.

OCR, evidence review, entity reconciliation and embeddings remain separate future work with source rights and verification requirements. A model cannot substitute for missing records or source validation.
